# ADR-002 — PDF vectorial primero

**Estado:** Aceptado

## Decisión
El MVP no utilizará OCR ni visión computacional para PDFs escaneados.

## Razón
Primero debe demostrarse la hipótesis geométrica usando datos vectoriales exactos. Añadir raster en esta etapa mezclaría problemas distintos y dificultaría medir la calidad del intérprete.
